# 坦克大战 · Battle City

一个使用原生 HTML + Canvas + JavaScript 实现的经典「坦克大战」网页小游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 🎮 玩法

- **守卫基地**：保护地图下方中央的金色鹰徽基地，基地被摧毁或生命耗尽则游戏结束。
- **消灭敌人**：击毁敌方坦克获得分数，清空一波后进入下一波（共 8 波，通关即胜利）。
- **砖墙可破坏**：子弹可击穿棕色的砖墙，灰色的钢墙无法破坏。

## 🕹 操作

| 操作 | 按键 |
| ---- | ---- |
| 移动 | 方向键 / WASD |
| 开火 | 空格 / J |
| 暂停 / 继续 | P |
| 开始 / 重新开始 | Enter |

## 🎯 敌人类型

- 🔴 基础坦克（红色）：100 分
- 🟠 快速坦克（橙色）：200 分，移动更快
- ⚪ 装甲坦克（灰色）：300 分，需要两发子弹

## 🚀 运行

直接双击 `index.html` 用浏览器打开即可，也可以本地起一个静态服务：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 🛠 技术

纯前端实现，单文件 `index.html`，包含：

- HTML5 Canvas 渲染
- 网格地图与像素级碰撞检测
- 敌方 AI（随机游走 + 瞄准基地）
- Web Audio 音效（开火、爆炸、敌人生成）
- 波次系统与分数 / 生命 / 波次 HUD
